## Tablas SmartPOS (ferretería / POS)

| Tabla | Propósito |
|---|---|
| `productos` | Catálogo: código, stock, precios, SAT |
| `proveedores` | Proveedores (legacy; UI simplificada sin proveedor) |
| `clientes` | Clientes para venta y CFDI |
| `ventas` | Encabezado de venta (folio, totales, forma pago) |
| `venta_items` | Líneas de cada venta |
| `empresa_fiscal` | Datos emisor + configuración PAC |
| `cfdi` | Facturas timbradas |
| `organizations` | SaaS / Stripe (suscripciones) |

### Productos — campos clave

- `codigo` — bigint, único por usuario.
- `codigo_text` — texto para búsqueda por prefijo (migración 014).
- `precio_compra` — sin IVA.
- `precio_mayoreo`, `precio_publico` — con IVA incluido.
- `margen_ganancia` — % sobre compra.
- `clave_sat`, `unidad_sat` — catálogo SAT.

<Callout type="warning">
La tabla `documents` (RAG con embeddings) **aún no está incluida** en las migraciones — llegará con [Chatbot con RAG](/docs/recetas/chatbot-con-rag).
</Callout>

Todas con **Row Level Security (RLS) estricta** — cada usuario solo ve y toca sus filas. La `waitlist` permite insert público pero lectura solo vía `service_role` (métricas en Inicio).
