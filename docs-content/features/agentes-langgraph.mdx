**LangGraph** arma agentes que dan varios pasos: pensar → usar herramienta → volver a pensar.

En SmartPOS el asistente vive en **`/chat`** (UI amigable) y usa el patrón **recover → decide → act**.

## En la app

| Pieza | Ubicación |
|---|---|
| UI | `/chat` — `LangGraphChat` |
| API | `POST /api/ai/agent` (SSE) |
| Grafo | `web/lib/agents/graph.js` |
| Instancia SmartPOS | `web/lib/agents/examples/recoverDecideAct.js` |
| Tools | `web/lib/tools/index.js` |

`/agent` redirige a `/chat`.

## Flujo del grafo

- **recover** — arma mensajes + system prompt en español (mostrador).
- **decide** — modelo con tools; elige herramienta o responde.
- **act** — ejecuta tools, emite eventos `tool_call`, vuelve a decide.

Eventos SSE: `reasoning`, `tool_call`, `token`, `done`, `error`.

## Config

```js
features.agents: true
features.toolUse: true
ai.agentModel: "gpt-4o"
OPENAI_API_KEY en .env.local
```

## Persistencia

Tras cada sesión se guarda en `ai_conversations` / `ai_messages` (best-effort). Cuenta en métricas de Inicio.
