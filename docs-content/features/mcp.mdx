**MCP** conecta tu app con clientes de IA (Cursor, Claude Desktop, hardware ESP-Claw) mediante herramientas estándar.

Activación: `features.mcp: true` en `web/config.js`.

## Servidor MCP en SmartPOS

### `/api/mcp` — registry completo

Expone todas las tools de `web/lib/tools/index.js`:

- `buscar_productos`, `gestionar_inventario`, `registrar_venta`, `enviar_email`, etc.

Requiere usuario autenticado (cookies de sesión).

### `/api/mcp/productos` — solo consultas

Endpoint dedicado a **inventario en lectura**:

- `buscar_productos`, `obtener_producto_por_codigo`, `listar_productos`, `productos_bajo_stock`

→ Guía de uso: [MCP productos](/docs/smartpos/mcp-productos)

## Implementación

| Archivo | Rol |
|---|---|
| `web/app/api/mcp/route.js` | HTTP Streamable MCP (registry) |
| `web/app/api/mcp/productos/route.js` | MCP solo productos |
| `web/lib/mcp/server.js` | Servidor registry |
| `web/lib/mcp/productosServer.js` | Servidor productos |
| `web/lib/mcp/client.js` | Cliente para MCPs externos |

## Cliente MCP

`createMcpClient(url)` en `web/lib/mcp/client.js` conecta a cualquier servidor Streamable HTTP — útil para consumir Gmail, Notion o ESP-Claw en Sem 8–9.
