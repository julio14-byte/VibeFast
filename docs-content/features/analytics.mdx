## Métricas en Inicio (SmartPOS)

Sin PostHog, SmartPOS ya muestra **métricas reales** en `/dashboard`:

| KPI | Fuente |
|---|---|
| Waitlist | tabla `waitlist` |
| Signups MVP | tabla `profiles` |
| Sesiones chat IA | tabla `ai_conversations` |

Requiere `SUPABASE_SERVICE_ROLE_KEY` en el servidor. Config en `web/config.js`:

```js
productMetrics: {
  enabled: true,
  founderEmails: [], // o ["tu@email.com"]
}
```

→ Detalle: [Inicio y métricas](/docs/smartpos/inicio-y-metricas)

## PostHog (opcional)

Activación: `features.posthog: true` + en `web/.env.local`:

- `NEXT_PUBLIC_POSTHOG_KEY`
- `NEXT_PUBLIC_POSTHOG_HOST` (default `https://us.i.posthog.com`)

Eventos críticos del boilerplate: `signup`, `core_action`, `ai_call`, `tool_executed`.

Útil desde Sem 6 para customer development → [Analytics para decidir](/docs/deploy/analytics-para-decidir).

## Fallback `events`

Tabla `events` en Supabase si no usas PostHog — insert desde el cliente con RLS (solo ves tus eventos).
