## Configuración (`/settings`)

Opciones **avanzadas**. Si solo vendes en mostrador, no necesitas entrar aquí todos los días.

### Importar productos (CSV)

Sube una lista con columnas como:

- `codigo`, `nombre`, `stock`
- `precio_compra`, `precio_mayoreo`, `precio_publico` (o margen)
- `clave_sat`, `unidad_sat` (opcional)

El sistema crea o actualiza productos por **código**. Verás resumen: creados, actualizados, errores.

### PAC sandbox (facturas de prueba)

Formulario para conectar tu PAC en modo prueba:

- Provider, URL sandbox, API key / secret
- Se guarda en `empresa_fiscal`

Tras guardar, prueba timbrar desde **Facturas**.

### Token MCP (Claude Desktop)

En **Configuración** → **MCP · Claude Desktop**:

1. **Crea una API key permanente** (`spos_...`) — recomendado
2. Copia el JSON para `claude_desktop_config.json` (Claude Desktop → Settings → Developer)
3. Reinicia Claude por completo (icono 🔨 junto al chat)

**Autenticación del endpoint** (`/api/mcp/productos`):

| Método | Uso |
| --- | --- |
| `Bearer spos_...` | API key (Claude Desktop + mcp-remote) |
| `Bearer eyJ...` | JWT corto (~1 h) vía `GET /api/mcp/token` |
| Cookie | Navegador con sesión SmartPOS |

**No uses «Conectores» en claude.ai** — no envían la API key; verás «No autenticado». Usa **Claude Desktop** con el JSON generado.

Requiere migración `019_mcp_api_keys.sql` y `SUPABASE_SERVICE_ROLE_KEY` en el servidor.

### Variables que afectan la app

| Variable | Uso |
| --- | --- |
| `OPENAI_API_KEY` | Chat y asistente |
| `STRIPE_*` | Suscripción Pro → [Configurar Stripe](/docs/instalacion/stripe) |
| `SUPABASE_SERVICE_ROLE_KEY` | Métricas waitlist/signups en Inicio |
| `NEXT_PUBLIC_SUPABASE_URL` + `ANON_KEY` | Base de datos |
| Stripe keys | Suscripción Pro (`features.payments`) |

Lista completa en `web/.env.example`.
