## Endpoint dedicado

**`https://tu-dominio.com/api/mcp/productos`**

MCP (Model Context Protocol) para **consultar inventario** desde herramientas externas (Cursor, Claude Desktop, ESP-Claw).

### Herramientas expuestas

| Tool | Descripción |
| --- | --- |
| `buscar_productos` | Búsqueda por nombre o código |
| `obtener_producto_por_codigo` | Detalle exacto por código numérico |
| `listar_productos` | Catálogo con paginación |
| `productos_bajo_stock` | Existencias ≤ umbral (default 5) |

Solo **lectura** — no vende ni edita desde este endpoint.

### Requisitos

- `features.mcp: true`
- Sesión Supabase (cookies) o usuario autenticado en el cliente

### Registry completo

`/api/mcp` expone **todas** las tools (ventas, email, etc.). Usa `/api/mcp/productos` si solo necesitas consultas de catálogo.

### Cursor

```json
{
  "mcpServers": {
    "smartpos-productos": {
      "url": "http://localhost:3000/api/mcp/productos"
    }
  }
}
```
